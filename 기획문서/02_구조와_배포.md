
## 규칙
- 버튼 동작: `data-act="이름"` → 각 screen 의 `actions[이름](버튼, 해당 기록, 이벤트)`
- 폼: `data-form="이름"` + 입력에 `name` → `forms[이름](폼, {name: 값})` (값은 trim)
- 세그먼트: `<div data-seg="상태키"><button data-v="값">` → `S[상태키]=값` 후 refresh
- 화면 HTML 은 템플릿 문자열. 사용자 입력은 반드시 `esc()`
- 종목 키는 DB에 저장되므로 바꾸지 말 것(추가만)
- 의도적 단순화에는 `// ponytail:` 주석으로 한계와 개선 방향 표시

## 로컬 실행
- `npm install` 후 `npm run dev` → http://localhost:5180 (Claude 데스크톱: `.claude/launch.json` 의 `godsaeng`)
- 빌드 확인: `npm run build` → `dist/`

## 배포
- `git push` (main) → GitHub Actions 가 `npm ci && npm run build` → Pages 배포, 2~3분
- Pages Source = **GitHub Actions** (10-23 전환 완료)
- 빌드 파일명에 해시가 붙어 휴대폰 캐시로 옛 코드가 섞이지 않음. sw.js 는 네트워크 우선

## Supabase 설정 (대시보드)
- Data API 켬, 새 테이블 자동 노출 켬, **자동 RLS 켬**
- Authentication → Sign In / Providers: 신규 가입 허용, 익명 로그인 끔, **Confirm email 끔(테스트용)**, 구글 미설정
- URL Configuration: Site URL / Redirect URLs 에 배포 주소 등록 권장(비밀번호 찾기·구글 로그인 대비)
- 앱에 들어간 키: Project URL + anon public 키(공개용). service_role / secret 키는 절대 코드·채팅에 넣지 않음
