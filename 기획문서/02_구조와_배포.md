## 규칙
- 버튼 동작: `data-act="이름"` → 각 screen 의 `actions[이름](버튼, 해당 기록, 이벤트)`
- 폼: `data-form="이름"` + 입력에 `name` → `forms[이름](폼, {name: 값})` (값은 trim)
- 세그먼트: `<div data-seg="상태키"><button data-v="값">` → `S[상태키]=값` 후 refresh
- 화면 HTML 은 템플릿 문자열. 사용자 입력은 반드시 `esc()`
- 종목 키는 DB에 저장되므로 바꾸지 말 것(추가만)
- 의도적 단순화에는 `// ponytail:` 주석으로 한계와 개선 방향 표시

## 로컬 실행
- `npm install` 후 `npm run dev` → http://localhost:5180 (Claude 데스크톱: `.claude/launch.json` 의 `godsaeng`)
- 빌드 확인: `npm run build` → `dist/`

## Supabase 설정 (대시보드)
- Data API 켬, 새 테이블 자동 노출 켬, **자동 RLS 켬**
- Authentication → Sign In / Providers: 신규 가입 허용, 익명 로그인 끔, **Confirm email 켬(10-26)**, 구글 미설정
- URL Configuration: Site URL / Redirect URLs 에 배포 주소 등록 권장(비밀번호 찾기·구글 로그인 대비)
- 메일 템플릿(한국어): `supabase/mail/confirm-signup.html`, `reset-password.html` → Authentication → Emails → Templates 의 Confirm signup / Reset password 에 붙여넣기
- 외부 메일(SMTP): Authentication → Emails → SMTP Settings. 기본 메일은 팀원 주소에만, 시간당 2통 → 실제 가입 인증·비밀번호 찾기엔 외부 SMTP 필수. 발송 주소는 나중에 이 설정만 바꾸면 됨(코드 변경 없음). 현재(10-26~): 발송 전용 Gmail `godsaeng.noreply@gmail.com` + 앱 비밀번호(smtp.gmail.com:465), 출시 때 도메인+Resend 로 교체 예정
- 앱에 들어간 키: Project URL + anon public 키(공개용). service_role / secret 키는 절대 코드·채팅에 넣지 않음

## 안드로이드 앱 (10-28~)
- Capacitor 8 이 `dist`(웹 빌드)를 앱 안에 넣어 실행. 화면 코드는 웹과 같음. 앱 안 주소는 https://localhost 라서 초대·메일 링크는 `state.js` 의 `WEB`(웹 주소)를 씀. 서비스워커는 앱에서 안 켬
- 시험판 받기: https://github.com/limjunmo915/godsaeng/releases/download/android/godsaeng.apk (폰에서 열어 설치, '출처를 알 수 없는 앱' 허용 필요). main 에 올릴 때마다 새로 빌드되고 버전 번호(versionCode)가 올라가 덮어 설치됨
- 서명: `android/app/test.p12`(비밀번호 godsaeng-test) — 시험용이라 공개돼도 됨. **Play 스토어 업로드 키는 따로 만들어 GitHub Secrets 에만 둠**
- 아이콘: `src/public/icon-512.png` 로 만든 mipmap(적응형 아이콘 바탕색 #9ED5F4), 스플래시는 밝은 바탕 + 아이콘
- 앱에서만 되는 기능은 플러그인으로 하나씩: 푸시(Firebase), 공유받기(안드로이드 공유 목록), Health Connect(워치), 백그라운드 GPS(`screens/track.js` 의 source 함수만 교체)
