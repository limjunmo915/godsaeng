- 프로필 페이지: 피드·랭킹·검색·알림·친구 목록에서 이름 누르면, 나 탭 '내 프로필 보기'
- 친구(크루 탭 → 친구): 닉네임 검색, 팔로우·맞팔로우(=친구), 받은/보낸 팔로우, 친구 약올리기, 초대 링크(?f=코드, 받은 사람은 가입·로그인 즉시 친구), 설정에서 검색 노출 끄기

- 차단(신고 창에서, 설정에서 해제): 서로 약올리기·댓글·반응 불가, 내 화면에서 상대 기록·댓글·약올리기 숨김. 랭킹엔 포함
- 가입: 생년월일(만 14세 이상, 저장 안 함) + 이용약관·개인정보처리방침 동의. 기존 회원은 다음 접속 때 동의 창
- 건강정보 별도 동의: 내 몸 탭·심박 입력 전. 설정에서 철회하면 신체 기록·평균 심박 삭제
- 나 → 설정: 약올리기 받기 끄기
- 나 → 설정: 탈퇴하기('탈퇴' 입력 확인 → 사진 파일 + 계정·모든 기록 삭제, 만든 크루는 남은 크루원에게)
- 나 → 설정: 프로필 사진(가운데 정사각형 160px·약 7KB, 서명 주소 7일 폰 저장으로 다시 안 받음), 닉네임, 주간 목표
- 나 → 내 몸(본인 전용): 출생연도·성별·키, 날짜별 체중·체지방률·골격근량·허리둘레·안정시 심박, 추이 그래프, BMI·기초대사량·오늘 총 소모
