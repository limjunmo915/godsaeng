## 지금까지 만든 기능 (2026-10-23 기준)
- 이메일 회원가입·로그인 (메일 인증 꺼둠, 구글 로그인 미설정)
- 크루: 만들기, 6자리 초대코드로 가입, 여러 크루, 탈퇴
- 기록: 종목 56종(스트라바 SportType 전체) + 빠른 선택 6개, 시간 한 칸 입력(29:44 / 1:05:00), 거리 km/m, 상승고도, 칼로리 자동 계산, 평균 심박, 체감강도, 장비, 사진 10장(업로드 시 압축·위치정보 제거), 약올리기 한마디, 공개 메모, 비공개 메모, 크루 공개/나만 보기, 크루에 숨길 항목, 출퇴근 태그, 비현실적 속도 차단, 수정·삭제
- 피드: 라이벌 현황(갓생 포인트 기준), 최근 약올리기 5개, 주간 목표 바, 반응 4종(🔥인정/😤질 수 없다/🙄그게 다야?/🛋️누워있음), 댓글, 공유 카드(인스타 4:5)
- 랭킹: 주/월/연 × 갓생 포인트/시간/거리/칼로리/횟수, 1등 왕관, 약올리기·견제 버튼
- 크루: 초대 문구 복사, 멤버, 챌린지(기준·목표·기간·내기)
- 나 → 운동 기록: 주간 비교, 주간·일간 스트릭, 월간 결산 카드, 12주 그래프, 기록 검색(날짜·종목·제목·메모), 캘린더(누르면 피드의 해당 기록으로 이동), 종목별 비중, 개인 최고 기록, 배지 15종, 장비 누적 거리, 설정
- 나 → 설정: 프로필 사진(가운데 정사각형 160px·약 7KB, 서명 주소 7일 폰 저장으로 다시 안 받음), 닉네임, 주간 목표
- 나 → 내 몸(본인 전용): 출생연도·성별·키, 날짜별 체중·체지방률·골격근량·허리둘레·안정시 심박, 추이 그래프, BMI·기초대사량·오늘 총 소모
- 알림함(앱 열 때 확인): 공지사항(패치 안내, `src/lib/notices.js`) + 받은 약올림·댓글·반응 최근 2주
- 건의·버그 제보(나 탭), 남의 기록·댓글 신고(깃발 버튼) → `feedback` 표, 운영자는 [Table Editor](https://supabase.com/dashboard/project/ghrjtbznjnvzwqthiahm/editor)에서 확인
- 약올리기 도배 방지(같은 사람 1분 1회), 2주 지난 약올리기 자동 삭제
