# 스트라바 프로필 페이지 벤치마킹 (2026-10-27)

목표: 다른 사람 프로필을 누르면 스트라바처럼 "그 사람의 통계 피드"가 나오게. 지금 갓생살기는 작은 미리보기 창뿐이라 차이가 큼.

## 1. 스트라바 프로필 구성 (공식 도움말 기준)
출처: [Your Strava Profile Page](https://support.strava.com/hc/en-us/articles/216917697-Your-Strava-Profile-Page), [Profile Page Privacy Controls](https://support.strava.com/hc/articles/115000164850-Profile-Page-Privacy-Controls), 메시지: [Tom's Guide](https://tomsguide.com/news/everything-you-need-to-know-about-strava-messaging), [TechRadar](https://www.techradar.com/health-fitness/fitness-apps/how-to-change-your-privacy-settings-on-stravas-new-messaging-feature), 진행 차트: [BikeRadar](https://www.bikeradar.com/news/strava-personalised-progress-chart/)

> 모바일 앱의 정확한 배치 순서는 공식 문서에 없음. 아래 순서는 사용자가 정리한 스트라바 앱 순서 + 도움말 항목. 픽셀 단위로 맞추려면 스트라바 앱 화면 캡처로 확인.

| 순서 | 스트라바 | 세부 |
|---|---|---|
| 1 | 프로필 사진·이름 | 아래에 지역, 구독자 표시, 대표 클럽, 소개(bio) |
| 2 | 팔로잉·팔로워 수 (+ 활동 수) | 숫자 누르면 목록 |
| 3 | 팔로우 버튼, 메시지 | 비공개 계정이면 "팔로우 요청" |
| 4 | 함께 아는 팔로우 | "○○, ○○님 외 n명이 팔로우" (비팔로워에게도 '수와 함께 아는 팔로우'는 보임) |
| 5 | 미디어 | 최근 사진 모음(웹은 최근 100장) |
| 6 | 이번 주 통계 | 이번 주 활동 수·거리·시간 + 최근 12주 막대(진행 차트, 상위 3종목) |
| 7 | 활동 | 활동 목록(종목·거리·시간·날짜), 4주 캘린더 |
| 8 | 통계 | 종목별 최근 4주 평균, 올해 누적, 전체 누적 / 남의 프로필에선 **나와 나란히 비교** |
| 9 | 그 밖 | 트로피·업적, 베스트 기록(1K·5K…), 클럽, 장비(신발·자전거), KOM/구간 기록 |

### 공개 범위 (프로필 공개 설정이 '팔로워'일 때, 팔로워가 아닌 사람이 보는 것)
- 보임: 사진, 이름, 소개, **이번 주 통계 요약(거리·시간 정도)**, 팔로잉·팔로워 **수와 함께 아는 팔로우**
- 안 보임: 지역, 사진 모음, 캘린더, 클럽, 트로피, 활동 목록, 막대그래프, 나와 비교, 장비
- 팔로우는 승인 요청

### 메시지 (2023 출시, 무료)
- 1:1과 그룹 대화. 받는 범위를 본인이 선택: **내가 팔로우하는 사람 / 서로 팔로우 / 아무도**
- 프로필 공개가 '팔로워'면 기본값이 '서로 팔로우'

### 유료(스트라바 구독)와의 관계
- **프로필 자체와 메시지는 무료.** 구독은 더 깊은 분석(진행 비교, 피트니스·피로도, 구간 순위, 경로 등)에 과금
- → 갓생살기도 프로필·친구 기능은 무료로 두고, PRO 는 "더 잘하고 싶은" 분석에 (04_전략과_로드맵 원칙과 같음)

## 2. 갓생살기와 비교 (지금 = 10-26 미리보기 창)

| 스트라바 항목 | 갓생살기 지금 | 차이 | 갖다 쓸 수 있는 것 |
|---|---|---|---|
| 사진·이름·지역·소개 | ✅ 미리보기 창에 있음 | 작은 창(모달) → **전체 화면 페이지**로 | |
| 팔로잉·팔로워·활동 수 | 친구 수만 | 팔로잉·팔로워 수, 전체 활동 수 없음, 목록 못 봄 | follows 표 |
| 팔로우 버튼 | ✅ | 같음 (승인제 대신 맞팔 규칙) | |
| 메시지 | ❌ | 없음 | 새로 (아래 4번) |
| 함께 아는 팔로우 | ❌ | "○○님 외 n명이 팔로우" 없음 | follows 표로 계산 |
| 미디어(사진 모음) | ❌ | 없음 | 운동 사진(photos) |
| 이번 주 통계 + 12주 막대 | ❌ (남의 것) | 나 탭엔 내 것만 있음 | **나 탭의 주간 비교·12주 그래프 재사용** |
| 활동 목록·캘린더 | ❌ (피드에 섞여 있음) | 그 사람 기록만 모아 보기 없음 | **나 탭의 검색 결과·캘린더 재사용** |
| 통계(4주 평균·올해·전체) | 이번 달 횟수만 | 종목별 누적 없음, **나와 비교** 없음 | calc.js sum() |
| 트로피·배지 | 내 배지 15종만 | 남의 배지 안 보임 | **badges() 재사용** |
| 베스트 기록 | 내 것만 | 남의 것 안 보임 | 나 탭 개인 최고 기록 재사용 |
| 클럽 | ❌ | 그 사람의 크루 안 보임 | crews (같은 크루만 공개가 안전) |
| 장비 | 내 것만 | | gear (크루·친구는 이미 열람 가능) |
| 구간·KOM | ❌ | GPS 필요 → 로드맵 ⑤ 이후 | |
| 갓생살기 전용 | 약올리기·스트릭·갓생 포인트 | 스트라바엔 없음 → 프로필에 **스트릭·이번 주 갓생 포인트·약올리기 버튼**을 넣으면 차별점 | |

## 3. 공개 범위 제안 (갓생살기 규칙에 맞춤)
| 보는 사람 | 보이는 것 |
|---|---|
| 아무나(검색 노출 켬) | 사진(작게)·이름·지역·소개, 팔로잉·팔로워·활동 수, 함께 아는 팔로우, **이번 주 요약 숫자(횟수·시간)**, 잠긴 최근 활동 |
| 팔로우만 한 사람 | 위와 같음 + 사진 크게 보기 |
| **친구·크루** | 전부: 미디어, 이번 주 통계·12주 막대, 활동 목록·캘린더, 통계·나와 비교, 배지, 베스트 기록, 장비, 스트릭, 약올리기·메시지 버튼 |

- '나만 보기' 기록은 누구에게도 집계·표시 안 함. 숨긴 심박·칼로리도 그대로 숨김(crew_workouts 사용)
- 남의 숫자 요약은 서버 함수로 숫자만 돌려줌(기록 원본 X)

## 4. 메시지 기능 판단
- **가능**: Supabase 표 하나 + 실시간 구독으로 1:1 대화. 기술 난이도 중간
- **주의**
  - 푸시 알림이 아직 없음(로드맵 ④) → 앱을 열어야 메시지를 봄. 대화 경험이 반쪽
  - 1:1 대화는 괴롭힘·미성년자 접촉 위험이 가장 큰 기능 → **친구(맞팔)끼리만**, 신고·차단 연동, 메시지 보관 기간 정해 방침에 기재
  - 개인정보처리방침에 메시지 항목·보관 기간 추가
- **추천**: 프로필 페이지 먼저 → 푸시 알림(④)과 함께 **친구끼리 1:1 메시지**

## 5. 만드는 순서 제안
1. **전체 화면 프로필 페이지** (나 탭 구성 재사용): 머리(사진·이름·지역·소개) → 팔로잉/팔로워/활동 수 → 버튼(팔로우·약올리기) → 함께 아는 팔로우 → 미디어 → 이번 주 + 12주 막대 → 활동 목록 → 통계(나와 비교) → 배지·베스트 기록·장비
2. 내 프로필도 같은 페이지로(나 탭 맨 위 "내 프로필 보기"), 팔로잉·팔로워 목록 화면
3. 메시지(친구끼리) — 푸시 알림과 함께
4. 구간·KOM — GPS(⑤) 이후
