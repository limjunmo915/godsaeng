### ③ 미디어 전체 (캡처 3번)
가운데 사진 + 이름 → 탭 **[▦ Grid | ☰ List]** → 3열 정사각 격자(빈틈 2px)

### ④ 활동 목록 (캡처 4번)
그 사람 활동만 피드 카드 모양으로: 사진·이름 / 날짜·앱 / 종목 아이콘·지역 → 제목 → Distance·Time·Pace → 지도+사진 가로 넘김 → 공개 범위 안내 → **"17 gave kudos"(겹친 사진)** → 좋아요·댓글·공유

### ⑤ 통계 (캡처 5번)
위에 **종목 탭(자전거·러닝·수영 아이콘)** → 회색 띠 제목 + 줄 목록(라벨 왼쪽, 값 오른쪽 굵게)
- **AVG WEEKLY ACTIVITY**(최근 4주 평균): 횟수 · 시간 · 거리
- **YEAR-TO-DATE**: 횟수 · 시간 · 거리 · 상승고도
- **ALL TIME**: 횟수 · 거리 · …

### ⑥ You 탭 (캡처 14·15·16번) — 내 화면
- 상단: "You" + 내 사진(→ 내 프로필) · 🔍 · ⚙
- 탭 **Progress | Workouts | Activities**
  - Progress: 종목 칩(Swim) → This week + **Past 12 weeks** 그래프 → [See more of your progress] → **Streak 카드**(불꽃 안에 주 수 + 이번 달 점 달력)
  - Workouts: 추천 운동(**유료**)
  - Activities: **키워드 검색** + 내 활동 카드
### ⑦ Groups (캡처 10·11·12번)
- 상단 💬(메시지) · 🔍 · ⚙, 탭 **Active | Challenges | Clubs**
- Active: 참여 중인 챌린지(배지 + 이름 + 진행 막대 + "5 days left"). **"Design Your Own Challenge" = 유료(Unlock Group Challenges)**
- Challenges: 종목 칩 필터, 지난 그룹 챌린지, 공식 챌린지 Join
- Clubs: 클럽 만들기
### ⑧ 메시지 (캡처 13번)
"Messages" + ✏ 새 대화 + ⚙(누가 보낼 수 있는지). 빈 화면 "No Messages / Start a conversation to see it here"
### ⑨ 지도·기록 (캡처 8·9번)
- Maps: 경로 추천·히트맵 = **유료(Subscribe)**
- Record: GPS 지도 + 시간·속도·거리 + 종목·시작·경로 추가

### 스트라바 유료 경계 (캡처에서 확인)
| 무료 | 유료 |
|---|---|
| 프로필, 팔로우, **메시지**, 활동, 통계, 트로피, 클럽, 기본 12주 그래프, 스트릭 | 지도 경로 추천·히트맵, **직접 만드는 그룹 챌린지**, 추천 운동(Workouts), 진행 더보기 |

## 3. 갓생살기 프로필 페이지 설계 (스트라바 순서 + 우리 것)

화면: 전체 화면(피드 위에 덮는 페이지, ← 뒤로). 남의 것·내 것 같은 틀.

| # | 요소 | 남(친구·크루) | 남(그 외) | 나 |
|---|---|---|---|---|
| 1 | 상단바 | ← · ⋮(신고·차단·친구 끊기) | ← · ⋮ | ← · 공유(초대 링크) · ⚙ |
| 2 | 머리: 큰 사진 + 이름 + 지역 + 소개 | ✅ | ✅ | ✅ |
| 3 | 숫자 4칸: 팔로잉 · 팔로워 · 활동 · **주간 스트릭** | ✅ | ✅ (숫자만) | ✅ |
| 4 | 버튼 | [친구 ▾] [💬 메시지*] [😏 약올리기] | [팔로우] / [맞팔로우] | [초대 링크] [✏ 편집] |
| 5 | 함께 아는 친구(겹친 사진 + 모두 보기) | ✅ | ✅ (사진·이름만) | — |
| 6 | 미디어 줄 → 전체(격자/목록) | ✅ | 🔒 흐린 카드 | ✅ |
| 7 | 이번 주(주 종목 아이콘): 거리·시간·**갓생 포인트** + 12주 꺾은선 | ✅ | 이번 주 횟수·시간 숫자만 | ✅ |
| 8 | 목록 줄: 활동 › / 통계 › / 베스트 기록 › / 장비 › | ✅ | 🔒 | ✅ |
| 9 | 배지(개수 + 4개 + 전체) | ✅ | 🔒 | ✅ |
| 10 | 크루(같은 크루만 표시) | 같은 크루만 | — | ✅ |

\* 메시지는 5번 판단에 따라 나중(버튼 자리만)

하위 화면
- **활동**: 그 사람 기록만 피드 카드로(지금 피드 카드 재사용)
- **통계**: 종목 탭 → 최근 4주 평균 / 올해 / 전체 (횟수·시간·거리·상승고도·**갓생 포인트**), 남의 것은 **나와 나란히 비교** 칸
- **미디어**: 3열 격자 / 목록
- **팔로잉·팔로워 목록**, **함께 아는 친구 목록**

나 탭(You) 재구성
- 위: "나" + 내 사진(→ 내 프로필) · 🔍 · ⚙
- 탭 **진행 | 활동 | 내 몸**: 진행 = 종목 칩 + 이번 주 + 12주 꺾은선 + 스트릭 카드(불꽃 + 이번 달 점 달력) + 월간 결산·배지 / 활동 = 키워드 검색 + 캘린더 + 내 기록 / 내 몸 = 지금 그대로

디자인: 스트라바 배치·여백을 따르되 색은 우리 것(울트라마린 선·면, 약올리기만 노랑). 숫자 줄은 라벨 작게 위, 숫자 크게 아래(tabular).

## 4. 서버(공개 범위)
- 친구·크루: 기존 crew_workouts 로 그 사람 기록을 받아 화면에서 계산(숨긴 심박·칼로리는 이미 서버가 가림)
- 그 외: 서버 함수가 **숫자만**(팔로잉·팔로워·활동 수·스트릭·이번 주 횟수·시간) → profile_preview 확장
- 함께 아는 친구: 서버 함수(나와 그 사람 둘 다 친구인 사람 중 검색 노출 켠 사람)
- '나만 보기' 기록은 어디에도 안 셈

## 5. 메시지 판단
- 스트라바: 무료, 받는 범위 선택(팔로우한 사람 / 서로 팔로우 / 아무도), Groups 위 💬 함
- 갓생살기: **친구(맞팔)끼리만**, 신고·차단 연동, 보관 기간 방침 기재. **푸시 알림(로드맵 ④)과 함께** 넣는 걸 추천(앱을 열어야만 보이면 대화가 안 됨)

## 6. 만드는 순서
1. 전체 화면 프로필 페이지(3번 표 1~10) + 하위 화면(활동·통계·미디어·목록) + profile_preview 확장 SQL
2. 나 탭 재구성(진행 | 활동 | 내 몸), 12주 꺾은선·스트릭 카드
3. 메시지(친구끼리) — 푸시 알림과 함께
4. 경로·구간 — GPS(⑤) 이후
