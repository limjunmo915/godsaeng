# 13. 카카오·구글 간편 로그인 (2026-11-13)

로그인 화면 맨 위에 **카카오로 시작하기 / 구글로 시작하기**. 코드는 다 들어가 있고, 아래 설정을 끝낸 서비스만 버튼이 보임(`src/screens/oauth.js` 의 `PROVIDERS` 에 Claude 가 추가).

## 어떻게 돌아가나
- **앱:** 버튼 → 휴대폰 브라우저(크롬)로 카카오·구글 로그인 → 끝나면 `com.godsaeng.app://auth` 로 앱에 돌아와 로그인됨
  (구글은 앱 안 화면에서 로그인을 막아서 브라우저로 여는 게 필수)
- **웹:** 그 페이지에서 다녀옴
- **처음 간편 가입한 사람:** 생년월일·약관·실명을 못 받았으므로 첫 화면에 '약관 동의' 창이 뜨고 **성·이름·나라 + 생년월일(만 14세 확인, 저장 안 함) + 약관 동의**를 받음. 동의 전엔 앱을 못 씀
- 같은 이메일로 이미 가입한 사람이 구글로 로그인하면 같은 계정으로 이어짐(Supabase 가 이메일로 연결)
- 카카오는 이메일을 받으려면 '비즈 앱' 전환이 필요해서 **이메일 없이** 가입시킴(이름은 동의 창에서 받음)

## 설정 순서
### 0. SQL 020 실행 (먼저)
간편 가입은 생년월일을 줄 수 없어서, 가입 때 나이 확인은 이메일 가입에만 하고 간편 가입은 동의 창에서 하도록 바꿈.
[SQL Editor](https://supabase.com/dashboard/project/ghrjtbznjnvzwqthiahm/sql/new)에 `supabase/020-oauth.sql` 붙여넣고 Run

### 1. Supabase: 돌아올 주소 허용
[Authentication → URL Configuration](https://supabase.com/dashboard/project/ghrjtbznjnvzwqthiahm/auth/url-configuration) → **Redirect URLs** 에 아래 두 줄이 있는지 보고 없으면 **Add URL**

```
com.godsaeng.app://auth

```

### 2. 구글
1. [Google Cloud 콘솔](https://console.cloud.google.com/) → 위쪽 프로젝트 고르기에서 **godsaeng-ec705**(Firebase 가 만든 프로젝트) 선택
2. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면**(또는 'Google 인증 플랫폼') → 시작하기 → 앱 이름 `갓생살기`, 지원 이메일 `bommama412@gmail.com`, 대상 **외부**, 연락처 이메일 → 만들기
3. **클라이언트(사용자 인증 정보) → 클라이언트 만들기** → 유형 **웹 애플리케이션**, 이름 `supabase`
   - **승인된 리디렉션 URI** 에 추가: `https://ghrjtbznjnvzwqthiahm.supabase.co/auth/v1/callback`
   - 만들기 → **클라이언트 ID** 와 **클라이언트 보안 비밀번호**가 나옴(보안 비밀번호는 비밀 값 — 대화에 붙이지 말기)
4. [Supabase → Authentication → Sign In / Providers → Google](https://supabase.com/dashboard/project/ghrjtbznjnvzwqthiahm/auth/providers) → **켜기**, Client ID·Client Secret 에 3번 값 붙여넣기 → Save
5. 동의 화면이 '테스트 중'이면 등록한 테스트 사용자만 로그인됨 → **앱 게시(프로덕션으로)** 누르기(이름·이메일만 받으므로 구글 심사 없이 바로 됨)

### 3. 카카오
1. [Kakao Developers](https://developers.kakao.com/) → 카카오 계정으로 로그인 → **내 애플리케이션 → 애플리케이션 추가** → 앱 이름 `갓생살기`, 회사명 `갓생살기`(개인이면 이름) → 저장
2. **앱 키** 에서 **REST API 키** 복사(= Supabase 의 Client ID)
3. **카카오 로그인 → 활성화 설정 ON**, **Redirect URI** 에 `https://ghrjtbznjnvzwqthiahm.supabase.co/auth/v1/callback` 등록
4. **카카오 로그인 → 동의항목** 에서 **닉네임**, **프로필 사진** 을 '선택 동의'로(이메일은 비즈 앱만 돼서 안 켬)
5. **카카오 로그인 → 보안 → Client Secret → 코드 생성**, 활성화 상태 **사용함** → 코드 복사(비밀 값)
6. [Supabase → Providers → Kakao](https://supabase.com/dashboard/project/ghrjtbznjnvzwqthiahm/auth/providers) → **켜기**, Client ID = REST API 키, Client Secret = 5번 코드, **Allow users without an email 켜기** → Save

### 4. Claude 에게 "구글 켰어" / "카카오 켰어"
→ 버튼을 보이게 하고 배포·새 앱 빌드

## 확인
- 로그인 화면에 버튼이 보이는지 → 눌러서 로그인 → 앱으로 돌아오는지 → 처음이면 동의 창(실명·생년월일)
- 안 되면 오류 화면을 캡처(카카오 KOE 로 시작하는 코드, 구글 redirect_uri_mismatch 등)

## 한계
- 동의 창을 거치기 전 아주 짧은 순간은 로그인만 된 상태(앱 화면은 동의 창이 막음). 크루·친구가 없으니 볼 수 있는 기록도 없음
- 카카오 이메일이 없으면 '비밀번호 찾기'는 못 씀(카카오로 로그인하면 되므로 필요 없음)
- 아이폰 앱이 생기면 애플 로그인도 필수(앱스토어 규칙)
