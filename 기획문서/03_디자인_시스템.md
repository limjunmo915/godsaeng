# 디자인 시스템 (10-23 확정)

**컨셉**: 스트라바형 레이아웃 + 우리만의 색. 화면의 90%는 흰색·잉크, 브랜드색은 버튼·선택에만, 노랑은 약올리기에만 쓴다. 노랑이 보이면 "누가 날 약올렸다"는 신호.

## 색
| 토큰 | 밝은 모드 | 어두운 모드 | 쓰는 곳 |
|---|---|---|---|
| --brand (갓생 울트라마린) | #3D2EFF | #8C82FF | 주 버튼, 선택 탭, 그래프, 캘린더 운동한 날 |
| --taunt (약올림 옐로) | #FFE14D (글자 #3A3000) | 동일 | 약올리기 버튼·한마디·순위 차이·내기·슬로건 |
| --ink | #10121F | #ECEDF7 | 글자·숫자 |
| --bg (트랙 그레이) | #F5F6FA | #0D0F1A | 바탕 |
| --surface | #FFFFFF | #161929 | 카드 |
| --up / --down | #00875C / #D93A3F | #3FDCA4 / #FF7A7E | 증감, 경고 |

- 어두운 모드는 완전 검정 대신 남색 잉크. 휴대폰 설정을 자동으로 따름
- 운동 앱 주요 색과 겹치지 않음: 스트라바 주황, 나이키 검정·볼트, 토스/삼성 하늘, 카카오 노랑, 네이버 초록

## 글꼴·숫자
- Pretendard Variable (npm `pretendard`, 동적 서브셋)
- 숫자는 tabular-nums, 큰 수치는 22~24px 700~800, 단위는 작게(muted)

## 아이콘
- Tabler outline (npm `@tabler/icons`), `src/lib/icons.js` 목록에 있는 것만 빌드에 포함
- 이모지는 UI에 쓰지 않음. 약올리기 문구 같은 **사용자 대사 안**과 **반응 버튼**(🔥인정 😤질 수 없다 🙄그게 다야? 🛋️누워있음 — 사용자가 하는 한마디)에서만 허용

## 컴포넌트 규칙
- 피드 카드: 휴대폰에선 화면 꽉 차게(모서리 없음), 카드 사이 8px 회색 간격. 대표 수치 3개(거리·페이스·시간, 거리 없으면 시간·칼로리·포인트)를 크게, 나머지는 작은 줄
- 사진: 카드 폭 전체, 4:5 비율 고정(로딩 중 화면 밀림 방지)
- 반응 바: 이모티콘 + 이름 + 숫자, 한 줄. 좁은 화면(≤420px)에선 글자 12px·간격 축소. 피드 카드에는 약올리기 버튼 없음(운동하고 올린 사람을 약올릴 이유 없음 → 약올리기는 랭킹에서). 내 기록의 공유·수정·삭제는 카드 머리 오른쪽
- 입력칸: 48px 높이, 회색 채움, 포커스 시 브랜드 테두리
- 상단바 로고: 갓 + 하트 + 심박선 SVG(28px, 갓·하트 = --brand, 심박선 = --taunt) + '갓생살기' 글자. 로그인 화면은 글자 + 노란 점 그대로
- 프로필 사진: 없으면 첫 글자 원(아이디로 정한 색). 누르면 크게 보기 — 진짜 사진은 팔로우·크루·친구만, 사진 없으면 카톡식 기본 프로필(같은 색 바탕 + 사람 모양 + 이름)은 누구나
- 공지: 알림함 맨 위 연보라(--brand-soft) 상자, 최근 3개, 안 읽은 공지는 펼쳐 보임
- 반응한 사람: 반응 바 아래 겹친 사진 3개 + '민수 외 2명이 반응했어요'(스트라바 kudos 줄) → 누르면 이름 + 반응 목록 창, 이름 누르면 프로필
- 피드 카드 메모: 제목 바로 아래, 3줄 넘으면 접고 '더보기'(실제로 넘칠 때만 보임)
- 메시지: 상단 종이비행기(안 읽으면 빨간 점). 내 말풍선 = --brand 오른쪽, 상대 = 회색 왼쪽(단체방은 이름). 크루 방은 연보라 사람 아이콘 + '크루' 표시
- 휴대폰 뒤로 가기: 열린 창 → 프로필 → GPS 기록 → 메시지(방 → 목록 → 닫기) → 검색 페이지 → 피드가 아닌 탭 → 피드에서 '뒤로 버튼을 한 번 더 누르면 앱이 닫혀요'(반투명 배경, 2초) → 한 번 더 누르면 종료 (main.js popstate)
- 하단 탭 5개, 가운데 + 버튼만 브랜드색 채움
- 상단 띠(피드 뺀 탭): 연보라(--brand-soft) 40px, 왼쪽 '갓생살기' 굵게 + 응원 문구가 오른쪽→왼쪽으로 흐름(동작 줄이기 설정이면 멈춤). 광고 붙이면 같은 자리
- 기록 입력: 맨 아래 '올리고 약올리기' + '기록 안 올리기'(수정 중엔 '수정 취소')
- 실시간 측정: 오른쪽 아래 떠 있는 동그란 버튼(▶ 측정, 56px, 탭 바 위). 기록 입력 탭에선 숨김. 광고·다른 떠 있는 버튼을 그 자리에 두지 않음
- 공유 카드(1080×1350): 울트라마린 바탕(또는 사진 + 어두운 그라데이션), 흰 워드마크 + 노란 점, 큰 수치 3칸, 노란 약올리기 말풍선
- 앱 아이콘(10-23 교체): '갓 심박수' — 하늘색 바탕 + 남색 갓·하트 + 노란 심박선 + 반짝이 2개. 원본 `이미지생성/Gemini_Generated_Image_rqpm2zrqpm2zrqpm.png`(git 제외)에서 상자 안쪽만 잘라 모서리는 안쪽 색을 늘려 채우고, 원형 마스크 대비 90%로 축소
