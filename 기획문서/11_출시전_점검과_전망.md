# 11. 출시 전 전체 점검과 전망 (2026-11-11)

앱 전체 코드(화면 21개·계산·서버 SQL 18개)를 읽고, 가짜 데이터로 만든 연습용 화면에서 모든 탭을 직접 눌러 본 결과.
**한계:** 실제 계정·실제 폰으로는 확인하지 못함(로그인 정보는 받지 않는 규칙). 워치·블루투스·화면 꺼짐 GPS는 폰에서만 확인 가능.

## 1. 찾아서 고친 버그 (모두 배포됨)

| # | 증상 | 원인 | 확인 |
|---|---|---|---|
| 1 | **화면이 안드로이드 아래 버튼 줄(홈·뒤로)·위 상태 표시줄과 겹침** | 앱이 '화면 가장자리 여백' 값을 WebView 에게 물었는데, 기기·버전에 따라 0 을 주거나 늦게 줌. Capacitor 가 따로 넣어 주는 정확한 값을 안 쓰고 있었음. 또 설정·프로필·측정·메시지·검색 화면의 윗줄 높이가 여백만큼 모자라 뒤로 가기 버튼이 상태 표시줄에 올라탐. 아래에서 올라오는 창(알림·종목 고르기 등)이 버튼 줄 뒤까지 내려감 | 연습 화면에서 여백을 넣어 확인. **실제 폰은 새 앱 설치 후 확인 필요** |
| 2 | **취소한 GPS 측정의 경로가 다음 기록에 붙음** (측정 → '기록 안 올리기' → 나중에 웨이트를 직접 입력하면 그 웨이트 기록에 아까 달린 경로가 저장됨. 워치 기록 id 도 같은 문제) | 기록 화면을 비울 때 경로·워치 id 는 안 비움 | 고치기 전 재현, 고친 뒤 재확인 |
| 3 | 내 프로필의 **'프로필 편집'·톱니가 '장비 추가' 칸을 엶** | 설정을 톱니 화면으로 옮긴 뒤 예전 위치를 가리킴 | 재현·재확인 |
| 4 | 창(함께한 사람·종목 고르기 등)이 열려 있을 때 **안내 글·오류 글이 창 뒤에 가려 안 보임** | 안내 글이 창 아래 층에 그려짐 | 재확인 |
| 5 | 측정 끝난 뒤 "경로는 이 폰에서만 보여요"라고 나옴(경로 저장 동의한 사람에겐 틀린 말) | 경로 저장 기능 전 문구 | 재확인 |
| 6 | 알림을 못 불러오면 '불러오는 중…'에서 멈춤 | 실패 처리 없음 | 코드 확인 |
| 7 | 소소한 것: '닉네임으로 찾기' → '이름으로 찾기'(실명 전환 뒤 남은 말), '언제' 달력만 일요일 시작 → 월요일 시작으로 통일, 개인정보처리방침의 탈퇴 위치 설명 | | |

## 2. 이번에 더한 것

- **피드 새로 고침:** 지금까지는 앱을 껐다 켜거나 내가 글을 올려야 남의 새 글이 보였음. 이제 앱으로 돌아오면(1분 넘게 지났을 때) 자동으로, 피드 탭을 한 번 더 누르면 바로 새로 불러옴
- **끝까지 내리면 다음 글 자동으로**('더 보기' 버튼은 그대로 둠). ⚠️ 연습 화면이 숨겨진 상태라 자동 불러오기는 확인 못 함
- **계정·데이터 삭제 안내 페이지**(`delete-account.html`): Play 데이터 보안 양식의 '계정 삭제 URL'은 필수 칸. 10 문서와 설정 화면에 연결
- 댓글 하트 버튼 누르는 영역 넓힘

## 3. 비슷한 앱보다 모자란 것 (추천 순서)

| 순위 | 기능 | 스트라바·NRC·런데이 | 우리 | 왜 중요한가 |
|---|---|---|---|---|

| 8 | 코스·구간 랭킹(세그먼트) | 스트라바 핵심 | 없음 | 크고 어려움. 뒤로 |

## 4. 디자인에서 아쉬운 점

- **측정 화면 제목 옆 '시험 중' 꼬리표:** 핵심 기능이 미완성처럼 보임. 실제 폰 확인이 끝나면 떼기
- **'측정' 떠 있는 버튼이 카드 오른쪽 버튼(하트·신고·삭제)을 가림:** 아래로 내릴 때 숨기고 위로 올릴 때 보이게
- **기록 입력 화면이 김:** 종목·시간만 먼저 보이고 나머지(심박·체감 강도·장비·숨길 항목)는 '더 적기'로 접기
- **피드 카드가 빽빽함:** 숫자 3칸 + 보조 숫자 + 태그 + 함께 + 한마디 + 반응 4개 + 요약 + 댓글. 보조 숫자는 '더보기'로
- 다크 모드에서 종목 그림 뒤 밝은 네모가 떠 보임(그림을 투명 배경으로 다시 뽑으면 해결)
- 작은 버튼(댓글 신고·삭제 28px)은 안드로이드 권장(48px)보다 작음
- 스토어 스크린샷은 깐족이·랭킹이 보이는 화면으로(차별점)

## 5. 출시하면 어떻게 될까 (모의 검토)

**숫자는 예측이 아니라 가늠값.** 근거가 되는 바깥 숫자는 아래 두 가지뿐이고 나머지는 추정.
- 국내 러닝 인구 약 1,000만 명(문체부 인용 보도), 가장 많이 하는 운동이 달리기라는 답 7.7%(2025 국민생활체육조사, 2024년 4.8%) — [데일리안](https://www.dailian.co.kr/news/view/1670666), [세계일보](https://www.segye.com/newsView/20251216515676)
- 건강·운동 앱의 30일 뒤 남는 비율은 조사마다 3~12% — [Braze](https://www.braze.com/resources/articles/mobile-app-retention), [Userpilot](https://userpilot.com/blog/mobile-app-retention/)

**강점**
- '약올리기 + 깐족이'라는 뚜렷한 색. 스트라바는 진지하고 NRC·런데이는 혼자 뜀. 친구끼리 놀리는 앱은 빈자리
- 크루·친구에게만 보이는 닫힌 구조 → 기록 공개 부담이 적음(특히 초보·여성)
- 66종목(테니스·줄넘기·헬스까지) → 러닝 크루가 아니어도 됨. 회사 동료·가족 모임
- 운영비가 거의 0(무료 서버·무료 지도)

**약점**
- 푸시 없음·아이폰 없음·간편 로그인 없음(3번 표 1~3위). 이 셋이 퍼지는 속도를 가장 크게 깎음
- 친구가 없으면 빈 앱. 혼자 깔아서는 재미가 없음 → **'크루 단위로 들여오기'**가 유일한 성장 길
- 실명 가입은 신뢰엔 좋지만 가입 문턱
- 혼자 운영: 신고 처리·문의·장애 대응

**세 가지 경우 (출시 뒤 6개월)**
| 경우 | 조건 | 가입자 | 주에 한 번 이상 쓰는 사람 |
|---|---|---|---|
| 조용함 | 지금 상태 그대로, 지인에게만 알림 | 100~300명 | 30~80명 |
| 보통 | 푸시 + 간편 로그인 넣고, 러닝 크루 5~10곳에 직접 소개 | 1,000~3,000명 | 300~800명 |
| 잘됨 | 위 + 깐족이 스티커·결산 카드가 인스타에서 돌고, 아이폰 대응 | 1만 명 이상 | 3,000명 이상 |

**돈**
- 광고(띠 광고)만으로는 주간 사용자 1,000명일 때 월 수만 원 수준(추정). 서버 유료 전환(월 약 25달러)을 겨우 넘김
- 먼저 닿는 한계는 **사진 저장 1GB(무료)**: 사진 한 장 약 200KB → 약 5,000장. 주간 사용자 수백 명이면 몇 달 안에 참
- 수익은 광고보다 '크루 유료 기능(일정·출석·통계)'이나 깐족이 스티커 쪽이 앱 색깔과 맞음(04 문서)

**결론**
- 지금 상태로도 **지인·크루 수십~수백 명이 재미있게 쓰는 앱**은 충분히 됨. 비공개 테스트 15명이 그 축소판
- 그 이상으로 퍼지려면 기능을 더 늘리기보다 **푸시 → 간편 로그인 → 아이폰** 순서로 '들어오는 문'을 넓히는 게 먼저
- 비공개 테스트 2주 동안 볼 것: ① 초대받은 사람이 가입을 끝내는 비율 ② 일주일 뒤에도 여는 사람 수 ③ 약올리기를 주고받는 횟수. ②가 절반을 넘으면 보통 경우를 노려 볼 만함

## 6. 정식 출시 전 꼭 할 일 (기능 말고)

1. 방통위 위치기반서비스사업 신고(약관의 신고번호 칸)
2. 지도: OpenStreetMap 무료 지도는 사용자가 늘면 막힘 → 카카오·네이버 지도로
3. 실제 폰 확인: 겹침 수정, 화면 꺼짐 GPS, 워치 자동 올리기, 심박 센서, 함께한 운동
4. 서버 백업·오류 기록(지금은 사용자가 말해 줘야 앎)
5. 상표 출원(08 문서)
