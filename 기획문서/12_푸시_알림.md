# 12. 휴대폰 푸시 알림 (2026-11-12)

안드로이드 앱에서 반응·댓글·댓글 하트·약올리기·팔로우·메시지·함께한 운동이 오면 휴대폰 알림창에 띄움.
코드는 다 들어가 있고, **아래 '켜는 순서' 4단계를 끝내야 실제로 켜짐.** 그 전까지 앱은 지금과 똑같이 동작.

## 어떻게 돌아가나
```
누가 반응·댓글 등을 함
  → DB 트리거(SQL 019 push_event)가 '보낼 알림'을 대기열(push_queue)에 넣음
  → 대기열에 줄이 생기면 서버 함수(Edge Function 'push')를 깨움
  → 함수가 대기열을 비우며 받는 사람 기기(push_tokens)로 구글 FCM 에 전달
  → 휴대폰 알림창. 누르면 그 기록·프로필·대화방으로
```
- 자기 자신·차단한 사이에는 안 보냄. 알림이 실패해도 원래 동작(반응·댓글)은 그대로 됨
- **반응은 글마다 알림 하나로 합침:** "민수님, 지은님, 철수님 외 2명이 내 운동에 반응했어요" (새 반응이 오면 같은 알림이 바뀜)
- 메시지도 대화방마다 하나로 합침
- **앱을 보고 있을 땐 알림창에 안 뜸**(화면 안 깐족이·빨간 점이 대신)
- 끄기: 설정 → 알림 → 휴대폰 알림. 끄거나 로그아웃·탈퇴하면 그 기기 토큰을 서버에서 지움
- 알림 권한은 첫 안내 3장을 본 **다음 번 실행부터** 물음(첫 실행에 창이 겹치지 않게)

## 비밀 값은 어디에
| 값 | 어디에 | 누가 |
|---|---|---|
| `google-services.json` (앱이 Firebase 를 찾는 설정. 비밀 아님) | `android/app/` 폴더 → 저장소에 올림 | 사용자가 내려받아 폴더에 넣으면 Claude 가 올림 |
| Firebase **서비스 계정 열쇠**(알림을 보낼 권한. **비밀**) | Supabase → Edge Functions → Secrets 의 `FCM_SERVICE_ACCOUNT` | **사용자가 직접 붙여넣기.** 대화·코드에 남기지 않음 |
| Supabase 서버 열쇠 | 서버 함수 안에 Supabase 가 자동으로 넣어 줌 | 아무도 만지지 않음 |

## 켜는 순서
### 1단계. Firebase 프로젝트 만들고 설정 파일 받기
1. [Firebase 콘솔](https://console.firebase.google.com/) → 구글 계정으로 로그인 → **프로젝트 만들기** → 이름 `godsaeng` → 애널리틱스는 **끄기** → 만들기
2. 프로젝트 화면 가운데 **안드로이드 아이콘** 누름 → Android 패키지 이름에 `com.godsaeng.app` → **앱 등록**
3. **google-services.json 다운로드** → 받은 파일을 프로젝트 폴더의 `android/app/` 안에 넣기(나머지 단계는 '다음'만 눌러 넘기기)
4. Claude 에게 "파일 넣었어"라고 말하기 → 저장소에 올리고 새 앱을 빌드함

### 2단계. 서비스 계정 열쇠를 Supabase 에 넣기 (비밀 값, 직접)
1. Firebase 콘솔 왼쪽 위 **톱니 → 프로젝트 설정 → 서비스 계정** 탭 → **새 비공개 키 생성** → JSON 파일이 내려받아짐
2. 그 파일을 메모장으로 열어 **전체 선택 → 복사**
3. [Supabase Edge Functions Secrets](https://supabase.com/dashboard/project/ghrjtbznjnvzwqthiahm/functions/secrets) → Name 에 `FCM_SERVICE_ACCOUNT`, Value 에 붙여넣기 → **Save**
4. 내려받은 JSON 파일은 **지우기**(다른 곳에 올리거나 보내지 않기)

### 3단계. 서버 함수 만들기
1. [Supabase Edge Functions](https://supabase.com/dashboard/project/ghrjtbznjnvzwqthiahm/functions) → **Deploy a new function → Via Editor**
2. 함수 이름을 `push` 로(정확히) → 편집 칸의 내용을 모두 지우고 `supabase/functions/push/index.ts` 내용을 붙여넣기(Claude 가 클립보드에 복사해 줌)
3. **Deploy function**

### 4단계. SQL 019 실행
[SQL Editor](https://supabase.com/dashboard/project/ghrjtbznjnvzwqthiahm/sql/new)에 `supabase/019-push.sql` 붙여넣고 Run

## 확인하는 법
1. 새 앱을 깔고 로그인 → (두 번째 실행에서) 알림 허용
2. 앱을 **닫거나 홈으로 나간 뒤**, 다른 계정에서 내 글에 반응 → 몇 초 안에 알림
3. 안 오면: Supabase → Edge Functions → push → **Logs** 에서 오류 확인(캡처해서 Claude 에게)

## 한계·나중에
- 아이폰·웹은 아직 없음(웹 푸시는 별도 작업)
- 종류별로 끄기(예: 반응은 끄고 메시지만)는 없음. 필요해지면 설정에 추가
- 자동 약올림("3일째 누워있음")·주간 결산 알림은 이 구조 위에 예약 실행(pg_cron)만 더하면 됨
- 실패한 알림은 다시 보내지 않음(앱 안 알림함에는 남음)
