# 전략과 로드맵 (10-22 확정)

## 플랫폼
- **구글 플레이(안드로이드) 먼저**. 아이폰 사용자는 같은 서버의 웹앱으로 함께 사용
- 코드는 Capacitor 로 포장 → 나중에 같은 코드로 iOS 앱
- iOS 시작 신호: 아이폰 사용자 30%↑, 애플워치 연동 요청 반복, GPS 화면 켜기 불편 호소, 맥·테스터 확보
- 국내 20대는 아이폰 비율이 높음 → 아이폰 웹앱 품질도 같이 챙김

## 워치 연동
| | 갤럭시워치 | 애플워치 |
|---|---|---|
| 경로 | 워치 → 삼성헬스 → Health Connect → 안드로이드 앱 → Supabase | 워치 → 아이폰 건강(HealthKit) → iOS 앱 → Supabase |
| 과거 기록 | 권한 허용 기준 30일 전까지 | 제한 없음 |
| 자동 동기화 | 앱 열 때 + 백그라운드 | 백그라운드 알림(강제 종료 시 안 옴, 지연 사례) → 앱 열 때 보완 |
| 플러그인 | @capgo/capacitor-health (양쪽 공용, 무료) | 〃 |
| 심사 | Health Connect 권한 심사 | 건강 데이터 광고 사용·iCloud 저장 금지 |
- 자동으로 가져온 운동은 바로 올리지 않고 "운동 감지! 사진·한마디 붙여서 올릴래?" 알림 → 약올리기 컨셉 유지
- 스트라바 API 경유 불가: 2024.11부터 가져온 데이터를 본인에게만 표시 허용

## GPS
- 폰 GPS·지형 보정 데이터·구글 지도(안드로이드)·OSM 계열 지도 모두 무료. 심박은 워치·심박계 필요
- 필요한 것: 안드로이드 앱(화면 꺼져도 기록하려면 포그라운드 서비스), **위치기반서비스사업 신고**, 위치정보 이용약관 동의, 출발·도착 지점 가림(프라이버시 존)

## 수익화
- 원칙: 사람을 모으는 기능(약올리기·랭킹·공유 카드·내기·스트릭)은 영원히 무료. "더 잘하고 싶은" 기능만 유료
- 1단계(출시 후 수년): **네이티브 광고만**. 피드 5개당 1개(10-29), 카드 모양 + '광고' 표시, 피드 뺀 탭 상단 띠. AdMob 또는 카카오 애드핏 비교. 보상형 광고: 스트릭 지키기권, 슈퍼 약올림, 결산 카드 테마
- 2단계(월 사용자 1~3천, 한 달 잔존 30%↑): PRO 구독 — AI 코치, 회복 지수(sRPE 7일/28일), 체력·피로 그래프, 경기 기록 예측, 심박 구간, 주간 가이드. 맛보기(흐린 미리보기, AI 코치 주 1회 무료). 초기 가입자 '얼리 갓생러' 혜택
- 3단계: 스폰서 챌린지(헬스장·러닝화·보충제), 사내 운동 챌린지(1인당 월 1~3천 원)
- 4단계: 장비 교체 시 제휴 링크(수수료 표시 의무), 내기 커피 기프티콘
- 기각: 사진 저장 공간만 늘려주는 플랜
- 금지: 건강 데이터를 광고 타겟팅에 사용
- 무료 사진 정책(검토안): 기록은 영구 보관, 사진 원본은 6개월 후 미리보기(약 40KB)만 남김, 삭제 30일·7일 전 알림, 원본 내려받기 제공

## 비용·손익분기 (광고만, 추정)
- 고정비: Supabase Pro 약 35,000원 + 도메인 약 2,500원 = 월 약 37,500원
- DAU 1명 월 광고 수익: 보수 약 170원 ~ 낙관 약 500원 (노출 월 240회 기준, 단가 편차 큼)
- **손익분기 DAU 약 75~220명**. 매일 100명 넘으면 Pro 전환 검토
- 출시 비용: Google Play 개발자 등록 약 3.5만 원(1회). Apple 은 연 약 14만 원 + 맥
- 미니PC 자체 서버는 메인 비추천(정전·통신사 약관·민감정보 보호 책임) → 개발·백업용

## 법·세무 (수익 전)
- 직장 겸직 규정 확인, 종합소득세 신고, 수익이 꾸준해지면 사업자등록, 유료 판매 시 통신판매업 신고
- 개인정보처리방침, 건강정보(민감정보) 별도 동의, 국외이전·처리위탁 고지, 만 14세 미만 제한, 탈퇴 시 파기
- Google Play: 신규 개인 계정은 테스터 12명 × 14일 비공개 테스트 필수
