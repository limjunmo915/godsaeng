## 8. 수익화
| 단계 | 내용 |
|---|---|
| 원칙 | 소셜·기록 기능은 무료(사람이 모여야 함), "더 잘하고 싶은" 기능과 저장 용량에 과금. 건강 데이터는 광고 타겟팅에 절대 사용 금지 |
| 1. 광고 | 랭킹·통계 하단 배너만(피드 X), 보상형 광고: 스트릭 지키기권·슈퍼 약올림·결산 카드 테마. 전면 광고 X |
| 2. 구독 | 광고 제거, 고급 분석·코칭, 사진 원본 무제한, 커스텀 약올리기, 여러 크루 |
| 3. 브랜드·기업 | 스폰서 챌린지(헬스장·러닝화·보충제), 사내 운동 챌린지(1인당 월 1~3천 원) |
| 4. 제휴 | 장비 교체 시 쇼핑 제휴 링크(수수료 표시 의무), 내기 커피 기프티콘 |
| 법·세무 | 직장 겸직 규정 확인, 종합소득세 신고, 사업자등록(수익 꾸준해지면), 통신판매업 신고(유료 판매 시), AdMob 광고 ID 처리방침 기재 |
| 참고: 스트라바 | 매출 약 90% 구독(연간 위주), 배너 광고 없음, 스폰서 챌린지·브랜드 제휴, Metro 데이터 무료 제공 |
